Panduan Konsep: Array vs Object

Memahami kapan harus menggunakan Array, Object, atau Kombinasi keduanya adalah kunci utama pengembangan aplikasi web modern.

{ }

JavaScript Object

  • Fungsi: Menyimpan detail dari 1 entitas tunggal (Property & Value).
  • Pengaksesan Data: Menggunakan Key (`obj.nama` atau `obj['harga']`).
  • Operasi Kunci: `delete obj.key`, `'key' in obj`, `Object.keys(obj)`.
  • Contoh Kasus: Data akun user yang sedang login, konfigurasi aplikasi.
[ ]

JavaScript Array

  • Fungsi: Menyimpan kumpulan/daftar data terurut berdasarkan Indeks.
  • Pengaksesan Data: Menggunakan Indeks Angka (`arr[0]`, `arr[1]`).
  • Operasi Kunci: `.push()`, `.splice()`, `.map()`, `.filter()`, `.find()`.
  • Contoh Kasus: Daftar riwayat transaksi, antrean cetak, daftar tag produk.

Kombinasi Nyata: Array of Objects `[{...}, {...}]`

Mengapa struktur ini standar standar industri REST API dan database?

1. Struktur Terorganisir

Object memastikan tiap entitas produk punya atribut seragam (id, nama, harga).

2. Mudah Diolah (Array Method)

Daftar produk bisa difilter, diurutkan, atau dicari menggunakan method bawaan Array.

3. Mudah Render ke DOM

Dapat di-loop dengan `.map()` atau `.forEach()` untuk langsung dikonversi menjadi elemen HTML.
