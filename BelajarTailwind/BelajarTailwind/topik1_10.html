Tailwind CSS

Pembelajaran Tailwind CSS
Topik 1 sampai 18

Rangkuman lengkap materi Tailwind CSS dari dasar hingga tingkat lanjut lengkap dengan rincian kode utilitas, penjelasan mudah, dan visualisasinya.

TOPIK 01

Getting Started

Dasar memulai Tailwind CSS beserta konfigurasi awalnya.

Penjelasan: Bagian awal untuk menyiapkan lingkungan kerja, mulai dari memasang kerangka kerja via CDN, mengatur ekstensi editor agar fitur saran kode (autocomplete) aktif, hingga memastikan kecocokan browser.

Installation

<script src="https://cdn.tailwindcss.com"></script>

Memuat script CDN secara instan.

Editor Setup

Tailwind IntelliSense

Mengaktifkan autocomplete di VS Code.

Compatibility

Chrome, Firefox, Safari

Mendukung seluruh browser modern.

Upgrade Guide

npm install tailwindcss

Panduan migrasi versi terbaru.

TOPIK 02

Core Concepts

Konsep dasar utility class, interaksi state, dan sistem warna.

Penjelasan: Inti dari Tailwind menggunakan kelas utilitas kecil yang berdiri sendiri. Di sini kita belajar cara memberikan efek interaktif saat kursor menyentuh elemen (hover), saat diklik (focus), penyesuaian layar (responsive), hingga mode gelap (dark mode).
Utility Classes Hover Focus Responsive Dark Mode Theme Variables Colors Custom Styles Directives

Utility Classes & Hover State

<div class="bg-primary hover:bg-primaryDark transition duration-300">

Contoh interaksi transisi, hover, scale, dan shadow.

TOPIK 03

Base Styles

Tailwind memiliki Preflight sebagai reset CSS dasar untuk menyeragamkan gaya bawaan antar browser.

Penjelasan: Preflight berfungsi menghapus margin, padding, dan gaya standar bawaan dari berbagai browser (seperti Chrome atau Safari) agar tampilan website konsisten dan bersih dari awal.

Preflight (CSS Reset)

/* Otomatis menetralkan margin/padding bawaan browser */

Normalisasi style dasar elemen heading, body, dan list secara global.

TOPIK 04

Layout

Pengaturan posisi, tata letak, dan lapisan elemen web.

Penjelasan: Mengatur bagaimana suatu elemen ditampilkan di halaman web, apakah berdampingan, bertumpuk, atau melayang di atas elemen lain menggunakan kontrol posisi dan lapisan tumpuk (z-index).
Display block, flex, grid
Position relative, absolute
Overflow hidden, auto, scroll
Object Fit cover, contain
Object Position center, top
Visibility visible, invisible
Z-Index z-10, z-50
TOPIK 05

Flexbox & Grid

Sistem penataan elemen modern menggunakan Flexbox dan Grid.

Penjelasan: Dua sistem tata letak utama dalam web modern. Flexbox ideal untuk menyusun elemen secara baris/kolom searah, sedangkan Grid sangat ampuh untuk menyusun struktur layout kompleks dua dimensi (kolom dan baris sekaligus).
Flex Flex Direction Flex Wrap Grow & Shrink Order Grid Columns Grid Rows Gap Justify Content Align Items
Grid Kolom 1 grid-cols-1
Grid Kolom 2 grid-cols-2
Grid Kolom 3 grid-cols-3
TOPIK 06

Spacing

Pengaturan jarak luar (margin) dan ruang dalam (padding).

Penjelasan: Mengatur jarak antar elemen. Padding memberikan ruang di dalam batas elemen (antara isi dan garis tepi), sedangkan Margin mengatur jarak luar antar elemen.
Padding Utility p-5
Margin Utility mt-6
TOPIK 07

Sizing

Pengaturan lebar (width) dan tinggi (height) elemen.

Penjelasan: Menentukan ukuran dimensi elemen secara presisi, baik menggunakan persentase (misal setengah atau penuh layar), nilai tetap, maupun batasan ukuran minimum dan maksimum.
Width Penuh w-full
Width 75% w-3/4
Width 50% w-1/2
Width & Min/Max Width

w-full, max-w-md, min-w-0

Height & Min/Max Height

h-full, h-screen, max-h-96

TOPIK 08

Typography

Pengaturan gaya teks, ukuran huruf, dan spasi baca.

Penjelasan: Kumpulan utilitas untuk mempercantik teks, mulai dari ukuran font, ketebalan, perataan paragraf, jarak antar huruf (tracking), hingga jarak antar baris (leading).

Tailwind Typography text-3xl font-extrabold tracking-tight

Font Size + Font Weight + Text Color text-base font-semibold text-primary

Line Height digunakan untuk mengatur jarak antar baris teks agar nyaman dibaca. leading-8

Text Alignment & Transform (text-center, uppercase, tracking-widest)

Text Decoration & Underline Offset

TOPIK 09

Backgrounds

Pewarnaan latar belakang dan manipulasi visual visual.

Penjelasan: Mengatur warna latar belakang elemen, membuat efek transisi warna bertahap (gradient), serta mengatur posisi dan ukuran gambar latar.

Background Color

bg-primary

Background Image / Gradient

bg-gradient-to-br from-primary to-secondary
Background Position bg-center Background Size bg-cover Background Repeat bg-no-repeat
TOPIK 10

Borders

Pengaturan sudut, ketebalan, warna, dan garis luar tepi elemen.

Penjelasan: Mengatur garis tepi elemen, mulai dari melengkungkan sudutnya (border-radius), ketebalan garis, warna, gaya garis putus-putus, hingga garis luar (outline).
Border Radius rounded-3xl
Border Width border-4
Border Color border-primary
Border Style border-dashed
Outline outline outline-2 outline-offset-4 outline-primary

Contoh penggunaan garis luar (outline) di luar batas elemen.

TOPIK 11

Effects

Pengaturan bayangan, transparansi, dan efek visual elemen.

Penjelasan: Memberikan kesan kedalaman pada desain menggunakan bayangan kotak (box-shadow), mengatur tingkat tembus pandang (opacity), serta cara elemen berpadu dengan latar belakangnya (blend mode).
Box Shadow shadow-xl
Opacity opacity-75
Blend Mode mix-blend-multiply
TOPIK 12

Filters

Manipulasi visual grafis seperti blur, grayscale, dan kontras.

Penjelasan: Memberikan efek penyaringan grafis langsung pada elemen HTML, seperti membuat efek buram (blur), mengubah warna menjadi hitam-putih (grayscale), atau mengatur tingkat ketajaman warna (contrast).
Blur (Hover untuk clear) blur-[2px]
Grayscale grayscale
Contrast contrast-150
TOPIK 13

Tables

Pengaturan tata letak dan gaya komponen tabel HTML.

Penjelasan: Mengatur kerapian struktur tabel data, mulai dari menggabungkan garis border sel (border-collapse), mengatur jarak antar sel, hingga penempatan judul tabel (caption).
Caption Side: Top
Framework Type
Tailwind CSS Utility-first
border-collapse, caption-top
TOPIK 14

Transitions & Animation

Efek pergerakan halus dan animasi berulang pada elemen.

Penjelasan: Menghidupkan antarmuka dengan gerakan. Transition membuat perubahan gaya (seperti warna tombol saat di-hover) menjadi halus dalam durasi tertentu, sedangkan Animation membuat elemen bergerak sendiri secara kontinu (misal efek memantul).
transition-all duration-500 ease-in-out
animate-bounce
TOPIK 15

Transforms

Manipulasi geometri elemen seperti rotasi, skala, dan pergeseran.

Penjelasan: Mengubah bentuk geometri elemen secara visual tanpa mengganggu tata letak elemen di sekitarnya, seperti memutar posisi (rotate), memperbesar ukuran (scale), atau menggeser posisi (translate).
Rotate hover:rotate-6
Scale hover:scale-110
Translate hover:-translate-y-2
TOPIK 16

Interactivity

Pengaturan interaksi kursor, seleksi teks, dan perilaku scroll.

Penjelasan: Mengontrol cara pengguna berinteraksi dengan elemen web, seperti mengubah bentuk penunjuk kursor (cursor-pointer), mencegah teks disorot/diblok (select-none), atau mengatur apakah elemen bisa diubah ukurannya oleh pengguna (resize).
Cursor Pointer cursor-pointer
Select None (Anti-highlight) select-none
Resize Y (Kotak bisa ditarik) resize-y
TOPIK 17

SVG

Pengaturan warna isi (fill) dan garis tepi (stroke) pada elemen vektor SVG.

Penjelasan: Memungkinkan kita mewarnai ikon atau gambar vektor berbasis SVG secara langsung menggunakan utility class Tailwind layaknya elemen teks atau kotak biasa (fill dan stroke).
Contoh Styling SVG (Ikon Bintang) fill-primary stroke-slate-900 stroke-[1.5]
TOPIK 18

Accessibility

Pengaturan penyesuaian warna otomatis untuk aksesibilitas inklusif.

Penjelasan: Fitur aksesibilitas untuk memastikan website tetap nyaman dan terbaca dengan baik oleh pengguna berkebutuhan khusus, termasuk pengaturan pemaksaan kontras warna tingkat tinggi dari sistem operasi komputer/HP.
Forced Color Adjust forced-color-adjust-auto

Mengontrol pemaksaan palet warna sistem operasi (High Contrast Mode) pada elemen.
