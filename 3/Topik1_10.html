Bagian 1: Fondasi UI & Form (Topik 1 - 10)

TOPIK 01

Konfigurasi Tema (Tailwind Config)

Mengatur palet warna khusus dan jenis font default (misalnya Plus Jakarta Sans) lewat ekstensi tema pada skrip konfigurasi.

colors: { brand: { dominant: '#f8fafc', accent: '#2563eb' } }

TOPIK 03

Responsive Breakpoints

Mengatur tampilan berbeda antar HP dan layar laptop menggunakan prefix seperti md: dan lg:.

class="hidden md:flex md:w-1/2" (Disembunyikan di HP, tampil di Laptop)
TOPIK 04

Floating Labels dengan Peer

Animasi teks label naik ke atas saat kolom input difokuskan atau terisi teks.

TOPIK 05

Spacing & Sizing

Mengatur jarak vertikal/horizontal elemen form secara konsisten menggunakan space-y-*, padding (p-*), dan gap-*.

TOPIK 06

Typography Hierarchy

Mengatur bobot dan proporsi teks seperti text-2xl font-bold untuk heading serta text-xs text-slate-500 untuk catatan kaki/helper text.

TOPIK 07

Background Gradients

Gradasi warna modern pada sisi banner edukasi menggunakan utilitas arah gradien Tailwind.

bg-gradient-to-r from-blue-600 via-indigo-600 to-slate-900
TOPIK 08

Border Radius & Shadows

Membuat kartu terasa melayang dengan kelengkungan sudut besar (rounded-3xl) serta bayangan halus (shadow-xl).

TOPIK 09

Transitions & Interactive States

Umpan balik saat elemen ditekan atau disorot mouse (hover, active, focus).

TOPIK 10

Custom Animation & External CSS

Memadukan animasi keyframe buatan sendiri (efek cahaya blob) di file CSS eksternal dengan utility class Tailwind.
