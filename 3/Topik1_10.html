Modul 1

Getting Started

Tailwind CSS dapat diinstal via NPM, Vite/Framework CLI, atau Play CDN untuk prototipe cepat.

1. Install via NPM

npm install -D tailwindcss
npx tailwindcss init

2. Quick CDN Setup

<script src="https://cdn.tailwindcss.com"></script>
Editor Setup: Sangat disarankan memakai ekstensi VS Code resmi Tailwind CSS IntelliSense untuk fitur auto-complete class.
Modul 2

Core Concepts

State Modifiers

Gunakan prefix seperti hover:, focus:, active:.

Responsive Breakpoints

Mobile first: sm: (640px), md: (768px), lg: (1024px).

Layar: Mobile (<640px) Layar: Tablet (sm) Layar: Desktop (md+)

Arbitrary Values

Bisa masukkan nilai kustom menggunakan kurung siku [...].

bg-[#7000ff]
Modul 3

Base Styles (Preflight)

Tailwind otomatis menyertakan Preflight (reset CSS berbasis modern-normalize). Margin default semua elemen dihapus, heading tidak memiliki ukuran default bawaan browser, dan list tidak memiliki bullet default sebelum diberi utility class.

Tag <h1>, <p>, <button> tampil polos tanpa style browser bawaan sampai ditambahkan class Tailwind.
